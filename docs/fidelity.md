# 真值台账（Fidelity Ledger）

每个子系统的还原状态、依据与验收方式。**每次改动必须更新此表**；golden 快照只在有意的
语义变更后重生成，且必须在提交信息中说明原因——禁止用更新 golden 掩盖分歧。

状态枚举：

- **位精确** — 逐位/逐值与原作一致，有二进制依据
- **有界漂移** — 浮点路径，短窗口 epsilon 内一致且不发散
- **近似** — 行为形状对，数值未取证
- **未做** — 缺失或占位

依据栏：函数地址（th10.exe 反编译）、数据表地址、trace/回放编号、文档路径。

本表以 2026-11-21 第五轮代码为准。第一至三轮（t1–t13）完成关内逻辑、GUI／符卡、自机 VM、模式／存档与关外场景移植；第四轮（t14–t17）做资源瘦身、WASM 发布、旧代码清理与只读探针重写（不截图）；第五轮把 WASM 改为 `th10web` 资源包渐进加载，js 构建贴图与结局 CG 有损化，并删除旧背景、旧实体／弹幕／碰撞代码与各面独立包。逐轮过程见 git 历史；原更新记录见 `git show b4df88d:docs/fidelity.md`。
按取证、目视、回放／trace 与推测分类的剩余事项见 `docs/open_items.md`。
