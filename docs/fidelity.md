# 真值台账（Fidelity Ledger）

每个子系统的还原状态、依据与验收方式。**每次改动必须更新此表**；golden 快照只在有意的
语义变更后重生成，且必须在提交信息中说明原因——禁止用更新 golden 掩盖分歧。

状态枚举：

- **位精确** — 逐位/逐值与原作一致，有二进制依据
- **有界漂移** — 浮点路径，短窗口 epsilon 内一致且不发散
- **近似** — 行为形状对，数值未取证
- **未做** — 缺失或占位

依据栏：函数地址（th10.exe 反编译）、数据表地址、trace/回放编号、文档路径。
