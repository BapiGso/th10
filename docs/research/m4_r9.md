# M4 R9 取证：敌机 ANM 的 VM 结构、ECL 的 VM 操作与敌机更新（2026-11-02）

一行结论：原作敌机由 10 个槽 VM（`E+0xc0…E+0xe4`，`E = 敌机对象 +0x103c`）绘制，槽 VM 由 ECL 的 258/259/262/269 挂入活动表，每帧由 `FUN_0040dc80` 写位置（槽 0–7）、切换方向脚本（262 之后的 base+0…4）并做受击变色；263/264/272/273 产生不随敌机移动的自由 VM；敌机死亡与删除时槽 VM 只被打上删除标记，死亡特效为 `bullet.anm` 脚本 `0x167`（或 `0x164`/`0x16a`/`0x16d`）；Go 侧仍用 ebiten 精灵绘制敌机，没有这些 VM。

依据 th10.exe v1.00a 反编译与汇编（`tools/ghidra/dump.py`，项目 `%LOCALAPPDATA%/th10-ghidra-render`），以及 `assets/anm/*.anm`（经仓库 `th10/anm` 解析的临时程序，`.tmp/r9/layers/`）。新增 dump 在 `.tmp/ecl_dump/r9/`（清单见末尾）。前置文档：`m4_r8.md`（R8-A 与无法确定 #1）、`m4_r6.md`（R6-A 的精灵记录与 TFACTOR 颜色读法）、`m2_motion.md`（敌机管理器布局）、`ecl_truth.md`。

约定：地址为 th10.exe 虚拟地址。`E` 为 `FUN_0040dc80` 的参数，即敌机数据 `B+0x103c`（`FUN_0040cfb0` 0x40cfb0 中 `FUN_0040dc80(B+0x103c)`），`B` 为敌机对象本体（`operator_new(0x2518)`，`FUN_0040cfb0`）。`E+0xNN` 指 `E` 的偏移，`B+0xNN` 指本体偏移。`VM+0xNN` 指 ANM VM 基址偏移（字段名见 `anm/vm.go`）。`M` 为敌机管理器 `DAT_00477704`。标注 **（推测）** 的是未逐条核实的内容。无法确定的事项列在最后一节。

### B.2 每个操作（按原作操作码）

**258（`anmSelect`，`case 0x102`）**：`E+0xe8 ← S(param 0)`。不产生 VM。Go：`case opAnmSelect`（`game_ops.go:` 约 `case opAnmSelect`）。

**259（`anmSetSlot(slot, script)`，`case 0x103`）**：
1. `ESI = E+0xc0 + 4·slot`（`0x40ed74`），`FUN_00449630(&ESI)`（`0x40ed7d`）：旧句柄打删除标记，槽清零。此步在检查负脚本之前。
2. `TEST script, script; JL 0x411d18`（`0x40ed82`–`0x40ed84`）：**负脚本只删除旧 VM，不生成新 VM，直接退出。** Go 的 `anmSetSlot` 在此之前就返回（`game_ops.go` `if in.Opcode == opAnmSetSlot && script < 0 { return }`），**不删除旧 VM**。
3. `FUN_00448e30(M+0x30+4·E+0xe8, script, 5)`（`0x40edb2`），句柄写入槽（`0x40edbf`）。
4. `slot == 0`：`E+0xf0 ← script`，`E+0xec ← E+0xe8`（`0x40edc3`–`0x40eddf`）。
5. `FUN_00449450(&ESI)`（`0x40ede5`），然后进入共同出口 `0x40f103`：`slot == 0` 时写 `E+0x13a4/0x13a8`（尺寸）；`E+0x1444 & 0x10` 时 `FUN_004495e0(&slot)`（隐藏）。

**262（`anmSetMain(slot, script)`，`case 0x106`）**：
1. `FUN_00449630`（`0x40f002`）。无负脚本检查（ECL 的 262 参数均非负，见无法确定 #5）。
2. `FUN_00448e30(M+0x30+4·E+0xe8, script, 5)`（`0x40f01e`），句柄写槽。
3. `E+0x1444 & 0x10` 时 `FUN_004495e0`（隐藏）。
4. `slot == 0`：`E+0x13a4/0x13a8` 写尺寸；`E+0x1444 |= 0x1000`；`E+0xf4 ← script`；`E+0xf0 ← script`；`E+0xf8 ← 0`；`E+0xec ← E+0xe8`（`case 0x106` 的 `if (iVar26 == 0)` 块）。Go：`anmSetSlot`（`ECLFlags |= 0x1000`、`dirScript`、`MainScript`）。

**263（`anmPlay(file, script)`，`case 0x107`）**：
- 文件由**参数 0 的索引**取得（`M+0x30 + 4·idx`，`0x40ee15`–`0x40ee19`），**不是** `E+0xe8`。层 6（`0x40ee19` `PUSH 6`）。
- `FUN_00448e30`（`0x40ee21`）。句柄写入栈上临时变量（`EDI = ESP+0x1c`），不写槽。
- `JMP 0x40ee5b`：`FUN_00449450(&tmp)`（`0x40ee5f`）。随后 `E+0x1444 & 0x40000 == 0` 时 `VM+0x340…0x348 ← FUN_00418810(E+0x2c)`（= `E+0x2c` + (224,16,0)，`0x418810` 读取 `[EAX]`，`r9/func_418810.c`），否则 `VM+0x340…0x348 ← E+0x2c`（原始）。**只在生成时写一次**。
- 结论：263 生成的是自由 VM，不随敌机移动，不挂槽，不受 `E+0x1444 & 0x10` 影响。

**264（`anmPlayAbs(file, script)`，`case 0x108`）**：`FUN_00448e30(M+0x30+4·param0, param1, 6)`（`0x40ef05`），然后 `return 0`。不设 Offset（`FUN_00449870` 已清零），即绝对位置。自由 VM，层 6。

**269（`anmSetDir5(slot)`，`case 0x10d`）**：
1. `FUN_00449630(&slot)`（`0x40f0cb`）：删除旧句柄。
2. `FUN_00448e30(M+0x30+4·E+0xe8, E+0xf4 + 5, 5)`（`0x40f0f1`）：基址脚本 + 5，层 5，句柄写槽。
3. `FUN_00449450`；`slot == 0` 时写 `E+0x13a4/0x13a8`；`E+0x1444 & 0x10` 时隐藏。
