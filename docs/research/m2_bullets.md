- `Env.Hold` 位 1：原作让激光 calc 以游戏速度 0 运行，复刻同样传 0，但精灵脚本仍按正常速度运行，因为 `anm.Env` 无法表达速度 0。整个冻结标志目前未接线（见 §8）。
