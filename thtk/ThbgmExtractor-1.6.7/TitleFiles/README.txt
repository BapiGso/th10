このフォルダに曲目ファイルを追加すると、起動時に読み込まれるようになります。
Place the title files you need to load at start ThbgmExtractor up in this folder.

曲目ファイルのファイル名は titles_xxx.txt となっている必要があります。
The name of title file must be in format like 'titles_xxx.txt'.

曲目ファイルの入手・作成方法等はこちらをご覧ください。
For more information about the title files, see below.

https://smdn.jp/works/tools/ThbgmExtractor/#TitleFile (ja)


このファイルを削除しても動作に影響はありません。
This file can be deleted, and it is no affection to running ThbgmExtractor.
